# 기능별 모듈

기능마다 `src/features/<모듈>/` 폴더 하나를 쓴다. 화면 조립은 `src/app/` 에서 한다.

| 모듈 | 하는 일 | 입력 | 출력 | 단계 | 상태 |
|---|---|---|---|---|---|
| `map` | 네이버 지도와 서비스 범위 표시, 인증 오류 안내 | Client ID, 서비스 범위 | 지도 화면 | 1차 | 개발 완료 |
| `parking-lots` | 후보 주차장 30곳의 정보 관리, 지도 마커 표시 | 조사한 주차장 목록 | 주차장 데이터, 마커 | 1차 | 예정 |
| `congestion` | 주차장별 혼잡도 계산 | 주차장, 시간, 수집 데이터 | 혼잡도 | 2차 | 예정 |
| `guidance` | 사용자에게 알맞은 주차 공간 추천·안내 | 목적지, 혼잡도 | 추천 주차장, 경로 | 3차 | 예정 |

혼잡도 수집 방식과 안내 기준은 아직 정하지 않았다.

## 의존 방향

```
app → guidance → congestion → parking-lots
app → map
parking-lots 의 마커 표시 → map
```

- 모듈끼리는 서로의 내부 파일을 직접 고치지 않는다.
- 서버 API가 필요해지면 `src/app/api/` 에 라우트를 두고, 계산 로직은 해당 모듈에 둔다.
