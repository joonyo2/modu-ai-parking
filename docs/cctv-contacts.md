# 건물별 CCTV 연동 문의처

조사일: 2026-11-05. 공개 자료 기준이며, 전화번호는 문의 전에 공식 안내와 대조한다.

주차 관제 장비 업체와 CCTV 업체는 **모든 대상에서 공개 근거를 찾지 못했다.** 첫 문의에서 건물 측에 직접 묻는다. 빈칸은 공개 자료에서 못 찾았다는 뜻이다.

## 문의 순서

1. **천안도시공사:** 공영주차장 5곳을 한 창구로 묻고, 통합관제센터가 있다.
2. **종합운동장 스마트 주차 사업:** 주차관제센터와 CCTV 143대 계획(2025-09 보고회 기준)이 있고, 2026년 12월 무료 시범운영, 2027년 1월 유료화 예정으로 보도됐다. 시스템이 굳기 전에 연동을 묻는다.
3. **운영사가 확인된 곳:** 펜타포트 쪽의 케이엠파크, 하이파킹.
4. **관리사무소·건물 측 번호가 있는 곳:** 갤러리아, 오엔시티호텔, 파크푸르지오 2단지.
5. **연락처 미확인 건물:** 방문하거나 입점 상가, 사업자 정보로 관리단을 찾는다.

## 문의할 때 물을 것

1. 주차장 운영사, 관제 장비 업체, CCTV 업체는 어디인가요?
2. 입출차 기록이나 잔여 면수를 시스템에서 확인할 수 있나요?
3. 영상 원본 대신 잔여 면수 숫자만 받을 수 있나요?
4. 영상을 받아야 한다면 카메라 위치와 대수, 연동 방식은 어떻게 되나요?
5. 데이터 제공을 결정하는 곳은 어디이고, 어떤 서류와 절차가 필요한가요?
6. 시범 연동을 할 수 있는 층이나 구역이 있나요?

CCTV 영상에는 차량번호와 사람이 찍힐 수 있으므로, 영상을 받는 방식은 개인정보 처리 근거를 먼저 확인한다.
